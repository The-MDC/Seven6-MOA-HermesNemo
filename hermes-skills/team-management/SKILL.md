# hermes-ai-team
**Build an AI team of Hermes agents: SOUL, memory, vault, skills, nightly research, kanban, chief of staff, rituals, and Desktop Bots group chats.**

A Hermes skill that implements the complete team-building framework from the smfworks/hermes-ai-team repository, enabling a single Hermes install to be turned into a real team of AI colleagues.

**Core Components:**
- **N named agents** (Bots/profiles), each with its own SOUL, memory, skills, model, and lane
- **Second brain / vault** — where research and knowledge accumulate and compound
- **Nightly research** ("the dream function") — agents scanning their domains while you sleep
- **Self-improvement engine** — skills the agents write from experience, curated automatically
- **Shared kanban board** for durable task coordination
- **Hermes Desktop Bots + group chats** — team pods that coordinate in shared rooms
- **Chief of staff** agent that runs the coordination layer
- **Daily check-ins, weekly alignment loops, and one-on-ones**

**Phases (as described in the repository):**
1. Minimal Viable Team — a meaningful team of one in under 2 hours
2. Team growth phases with verification at every step
3. Full team implementation with all components

**Key Features:**
- Agent-consumable, phase-by-phase guide
- SOUL-based agent identity
- Persistent memory via mem9 vault
- Self-improving skills
- Nightly research automation
- Shared kanban for task coordination
- Desktop Bots + group chat pods
- Chief of staff coordination agent

**Dependencies:**
- mem9 for persistent memory
- mcp for tool integration
- SOUL framework for agent identity
- Desktop Bot mode
