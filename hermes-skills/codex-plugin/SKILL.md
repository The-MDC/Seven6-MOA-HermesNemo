# codex-plugin-cc
**Codex plugin for Claude Code integration**

A Hermes skill that integrates with the OpenAI codex-plugin-cc, enabling Codex functionality within Claude Code environment. Provides code review, task delegation, and automation capabilities through Codex's AI-powered code understanding.

**Core Features:**
- **Code review** — Codex-powered analysis of code changes with precise feedback
- **Task delegation** — Delegate coding tasks to Codex from within Claude Code
- **Automation** — Automate repetitive coding patterns and boilerplate generation
- **Context-aware** — Understands project context for relevant code suggestions

**Integration Points:**
- Works within Claude Code environment
- Leverages Codex's code analysis capabilities
- Provides structured code review outputs
- Supports task automation workflows

**Dependencies:**
- OpenAI Codex API access
- Claude Code environment
- Project context awareness
