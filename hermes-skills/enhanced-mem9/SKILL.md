# enhanced-mem9
**Extended persistent memory with advanced caching and query optimization**

A Hermes skill that extends the core mem9 persistent memory layer with advanced caching strategies, query optimization, and expanded platform integrations. Provides faster recall, larger context windows, and more efficient memory management for agent workflows.

**Advanced Features:**
- **Tiered caching** — Hot/ warm/ cold memory stratification for optimal access speeds
- **Query optimization** — Semantic caching, keyword fallback, and hybrid search priority routing
- **Context window expansion** — Effective context window multiplication through strategic memory retrieval
- **Platform-specific optimizations** — Claude Code, Codex, OpenCode, and Hermes Agent integration enhancements
- **Memory lifecycle management** — Automatic TTL, priority-based eviction, and storage optimization

**Supported Platform Enhancements:**
- **Claude Code** — Reduced token costs, faster context injection, priority skill recall
- **Codex** — Faster build-context cycles, optimized tool-call sequences
- **OpenCode** — Efficient multi-step workflow memory, cross-project recall
- **Hermes Agent** — Enhanced skill inheritance, cross-session capability retention

**Dependencies:**
- Core mem9 server (v1alpha2 API)
- Enhanced caching backend (Redis or TiDB compatible)
- Platform-specific plugin extensions
